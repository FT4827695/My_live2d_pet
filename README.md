# My_live2d_pet
Win系统下的简易桌面助手。  
Live2d-V2（ https://github.com/EasyLive2D ）的纯 Python（3.13） 版本。  
Vulkan 版本的 xllamacpp（ https://github.com/xorbitsai/xllamacpp ）作为后端。  
演示的模型为 Shizuku。
